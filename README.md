# One Line, One Laugh

make.fun bounty entry: a single hilarious line of at most 200 characters.

The entry program (`main.ts`, Node 22, stdlib only) writes the line to
`/output/entry.txt`:

> I tried meal prepping. My fridge now holds five identical regrets in matching containers.

Run it with `MAKEFUN_OUTPUT_DIR` set to choose the output directory, or
leave it unset to write to `/output`.
